# Concentrate

設計ドキュメント [../docs/design.md](../docs/design.md) の実装。
メニューバー常駐 + キーボード経路ブロック + タイマー自動解除 + 解除ホットキー/パスコード(Keychain)
+ スペース移動のバウンスバック + **設定画面 / ログイン項目登録 / URL スキーム**。

> 未実装: 配布(Developer ID 署名 + notarize。現状は Apple Development 署名のローカル運用)。
> 起動ホットキー: 本体では持たず、**Raycast 連携**側で設定する方針(下記 URL スキームで起動)。

## ホットキー

| キー | 動作 |
|---|---|
| `⌃⌥⌘P` | ロック中に解除パネルを開く |

## URL スキーム(Raycast 連携用)

| URL | 動作 |
|---|---|
| `concentrate://open` | ポップオーバーを開く |
| `concentrate://focus?minutes=25` | 25分の集中を開始(権限・パスコード設定済みのとき)|

Raycast の「Open URL」やシェル(`open "concentrate://focus?minutes=25"`)から呼べる。

## 設定(ポップオーバーの「設定…」)

- 解除パスコードの変更
- 「別スペースへ移動したら引き戻す」トグル
- **ログイン時に自動起動**(`SMAppService`。承認はシステム設定 > 一般 > ログイン項目)

## ビルドと起動

```sh
cd app
make run     # ビルド → .app 生成 → 起動
```

- `make build` … Swift パッケージのビルドのみ
- `make app`   … `build/Concentrate.app` を生成して ad-hoc 署名
- `make run`   … 上記 + `open` で起動
- `make log`   … 別ターミナルで実行ログを表示
- `make clean` … 生成物を削除

起動するとメニューバーに 🎯(scope アイコン)が出る。Dock には出ない。

## 権限

初回は **アクセシビリティ権限** が必要。

1. 起動時にダイアログが出る → 「システム設定を開く」
2. **システム設定 > プライバシーとセキュリティ > アクセシビリティ** で **Concentrate** を ON
3. メニューバーアイコンをクリックしてポップオーバーを開き直す(権限表示が更新される)

> 署名について: Apple Development 証明書があればそれで署名する(`make` が自動検出)。
> 証明書ベースで TCC が識別するため、**再ビルドしても権限が保持される**。
> 証明書が無い場合は ad-hoc 署名にフォールバックし、その場合はリビルドのたびに再許可が必要。

### 権限がうまく反映されないとき
過去に ad-hoc 署名で許可した entry が残っていると衝突することがある。リセットして再許可する:

```sh
make reset-perm        # tccutil reset Accessibility com.jayemdot.concentrate
# 必要なら システム設定 のアクセシビリティ一覧から古い "Concentrate" を − で削除
make run               # 再ビルド・起動して、改めて権限を許可
```

## 使い方

1. 初回起動時: **解除用パスコードを設定**(必須)。未設定だと集中開始できない
2. メニューバーアイコンをクリック → ポップオーバー
3. 15 / 25 / 50 分、またはカスタム分数で「集中開始」
4. ロック中: メニューバーが残り時間(MM:SS)になり、⌘Tab・⌃矢印などが効かなくなる
5. 解除:
   - 時間切れで自動解除
   - **解除ホットキー `⌃⌥⌘P`** → パスコードパネル → 正しいパスコードで即解除

## 解除パスコード

- Keychain に **salt + SHA256 ハッシュ** で保存(平文は保存しない)。
- リセットしたいとき: `make reset-passcode`(次回起動時に再設定を促す)。

## スペース移動の封じ込め(バウンスバック / M3)

トラックパッドの3〜4本指スワイプはイベントタップでは握り潰せず、`defaults` での無効化も
**ログインし直すまで反映されない**(調査・実機で確認済み)。そこで方式を変更:

- **スワイプ自体は止めない。代わりにスペースが変わったら即座に引き戻す。**
- 仕組み: `NSWorkspace.activeSpaceDidChangeNotification` を監視し、別スペース/フルスクリーンへ
  移ったら **ロック対象アプリを `activate()` して元へスナップバック**する(公開APIのみ)。
- 引き戻し先は「メニューバーを開く直前に最前面だったアプリ」。
- 挙動: スワイプ → 一瞬移動 → すぐ戻る。集中アプリとして「ここから出るな」を明示できる。
- システム設定は一切変更しないので、復元処理やクラッシュ時の後始末は不要。
- 邪魔なときはポップオーバーの「別スペースへ移動したら引き戻す」トグルを OFF に。

## 脱出ハッチ(重要)

- 設計方針 FR-2a により **強制終了(⌘⌥Esc)は意図的にブロックしない**。パスコードを忘れても脱出できる安全弁。
- アプリが死ねばイベントタップも消えるので、キー操作はすぐ元に戻る
  (スワイプ設定は次回起動時に自動復元)。

## 動作確認の観点

- [ ] メニューバーにアイコンが出る / Dock に出ない
- [ ] ポップオーバーから時間を選んで開始できる
- [ ] ロック中 ⌘Tab / ⌃← / ⌃→ / ⌘` / ⌘H が効かない
- [ ] メニューバーの残り時間が秒単位で減る
- [ ] 0 になると自動解除され、キー操作が元に戻る
- [ ] 「強制解除」ボタンで即解除できる
- [ ] ⌘⌥Esc(強制終了)は効く(=脱出できる)
