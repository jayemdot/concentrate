# Concentrate

タスクに集中するための macOS アプリ。集中セッション中は、いま開いているアプリ/フルスクリーンから
移動できないようにロックし、時間経過またはパスコードで解除する。

## 構成

| パス | 内容 |
|---|---|
| [docs/design.md](docs/design.md) | 設計ドキュメント(仕様・技術・限界・マイルストーン) |
| [app/](app/) | 本体(メニューバー常駐アプリ)。`cd app && make run` |
| [poc/m0-eventtap/](poc/m0-eventtap/) | CGEventTap 検証用 PoC |

## 主な機能

- メニューバー常駐のポップアップから時間を指定して集中開始
- ⌘Tab・キーボードでのスペース移動などの離脱経路をブロック(CGEventTap)
- トラックパッドのスワイプは「別スペースへ移ったら引き戻す」バウンスバックで封じ込め
- 時間経過、または解除パスコード(`⌃⌥⌘P`)で解除
- 強制終了(⌘⌥Esc)は意図的にブロックしない安全弁

詳細は各ディレクトリの README を参照。

## 必要環境

- macOS 14 以降(開発は macOS 26 / Swift 6.3 / Xcode で確認)
- アクセシビリティ権限(イベントタップに必要)
