# M0 PoC — CGEventTap で脱出キーを握り潰す

設計ドキュメント([../../docs/design.md](../../docs/design.md))の **M0** を検証する最小実装。
「⌘Tab・⌃矢印などの“他アプリ/他スペースへの移動”をイベントタップで本当にブロックできるか」を確認する。

## 検証したいこと
- CGEventTap(`.cgSessionEventTap` + `.headInsertEventTap`)で対象キーを `nil` 返し(握り潰し)できるか。
- アクセシビリティ権限のフローが期待どおり動くか。
- タップが無効化されたときに自動再有効化できるか。

## 実行方法

```sh
cd poc/m0-eventtap
swift run
```

初回は **アクセシビリティ権限** が必要。

1. 実行するとダイアログが出るので「システム設定を開く」。
2. **システム設定 > プライバシーとセキュリティ > アクセシビリティ** で、
   起動元(ターミナル/iTerm 等)、またはビルドされたバイナリを **ON** にする。
3. もう一度 `swift run`。

> ⚠️ CLI バイナリの権限は「起動元のターミナルアプリ」に紐づくことが多い。
> うまく動かない場合はターミナルアプリ自体を許可リストに追加する。
> 署名なしバイナリはリビルドで再許可を求められることがある(M4 で署名対応予定)。

## 期待する挙動
- `🟢 ロック中` と表示されたら、⌘Tab / ⌘` / ⌃← / ⌃→ / ⌃↑ などを押す。
- 握り潰されたキーが `🚫 握り潰し: …` とログに出て、**実際の切替が起きない**こと。
- 終了は **Ctrl-C**(⌘Q も握り潰すため)。
- ⌘⌥Esc(強制終了)は **わざと素通し**する(設計方針 FR-2a)。

## 既知の注意点 / この PoC で分かること
- **トラックパッドの3本指スワイプは対象外**。ジェスチャは WindowServer がより低レイヤで処理するため、
  イベントタップでは安定して握り潰せない → 本体ではセッション中だけシステム設定で無効化する方針(設計 §7.3)。
- **Mission Control 専用キー(F3 のメディアキー)** は通常の keyDown ではなく systemDefined イベントとして来るため、
  この PoC では拾えない場合がある。本体では systemDefined タップの追加要否を判断する。
- ログ出力をコールバック内で行っているが、キー入力頻度なら問題ない。本体では I/O を最小化する。
